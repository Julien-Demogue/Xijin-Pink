# Red Team

Reproducible attack scripts, run **from the Attacker PC only**, against the team's
own fictional SI on the `RESILIENCE-G<n>` hotspot. Each scenario must produce an
**observable effect** the monitoring can detect, and be compatible with an
automatic response you can demonstrate.

Strictly out of scope: campus networks, other teams, third-party/Internet
services, any real data. Anything that risks leaving the lab must be stopped and
reported to a coach.

For each scenario, document: goal, exact request/commands, expected observable
effect, and the expected automatic response. Candidate scenarios are listed in
[../docs/architecture.md](../docs/architecture.md#5-candidate-attack-scenarios).
